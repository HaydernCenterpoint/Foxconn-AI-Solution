# Obsidian vault — FII AI

Mở folder này như vault:

1. Obsidian → Open folder as vault
2. Chọn `obsidian-fii-ai`
3. Bắt đầu ở [[Home]]

Đây là knowledge base, không phải runtime. Nguồn quyết định release vẫn nằm trong `docs/release-evidence/`.

## Cấu trúc

| Folder | Việc gì |
|---|---|
| `00 Inbox` | Capture nhanh, chưa phân loại |
| `10 Project` | Status, scope, roadmap, repo map |
| `20 Evidence` | Bằng chứng đã chốt (link ra `docs/`) |
| `30 Decisions` | ADR / go-nogo |
| `40 Runbooks` | Lệnh chạy, gate, operator |
| `50 Design` | Material 3, SPA, icon |
| `60 Systems` | ClientPLC, backend, UI, ODF, Odysseus |
| `70 Conventions` | Secrets, ranh giới SPA, git pin |
| `80 Journal` | Daily notes |
| `90 Templates` | Template cho note mới |

New file mặc định vào `00 Inbox`. Daily note vào `80 Journal`.
