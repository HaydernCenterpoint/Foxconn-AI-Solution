        Bốn luồng thực thi

        Các deliverable được chia theo layer để không chờ nhau ngoài những contract bắt buộc.

            A · Data platform

            Telemetry &amp; integration

              - TimescaleDB schema, migration, benchmark và rollback plan.

              - Connector ERP/file/MES với retry, dead-letter và dashboard trạng thái.

              - Giao telemetry schema thật ở checkpoint tuần 2.

            B · Event &amp; AI

            CEP, prediction &amp; RCA

              - Chốt kiến trúc CEP và event schema trong sprint đầu.

              - Migrate alarm rules, đo event-to-alert latency và xây inference service.

              - Trả API alert/RCA để UI tích hợp ở tuần 5–6.

            C · Core backend

            Asset modeling &amp; security

              - Giao asset schema và asset_id trong ngày 1–3.

              - Asset CRUD, liên kết tài liệu, search và health score.

              - RBAC, rate limit, validation và RFC 7807 trước staging.

            D · Frontend &amp; QA

            Product surface &amp; evidence

              - UI shell/mock, Asset Browser, dashboard và biểu đồ vận hành.

              - Thay mock bằng API thật tại checkpoint tuần 5.

              - E2E, performance, security audit và hỗ trợ go-live.

                Managed staging

          Owner Production Pilot

          Accountable: Deployment Owner / Platform Operations Lead.

            - Operator: chạy pilot manifest và quản lý managed staging.

            - Independent reviewer: xác nhận evidence; không được là operator.

            - Security owner: phê duyệt ingress, TLS/mTLS, secret-manager và rotation.

            - Data/source owner: phê duyệt retention, phạm vi connector và nguồn dữ liệu.

          Go: đủ 16 managed checks, attestation độc lập, TLS/mTLS hoạt động, secrets không xuất hiện trong Git/logs và evidence được retention tối thiểu 90 ngày.

          No-go: bất kỳ check nào fail/thiếu, role bị chồng lấn, secret lộ, hoặc không chứng minh được rollback về deployment và secret version đã duyệt.

          Rủi ro cần theo dõi

            - Chậm asset schema sẽ chặn mock/API của cả ba luồng còn lại.

            - Data cutover phải có dual-write, validation query và rollback đã kiểm thử.

            - Quyết định CEP muộn có thể làm đổi event contract và trì hoãn UI.

            - Không được suy diễn production readiness từ CI hoặc local rehearsal; staging là gate riêng.
