            Telemetry & integration

              - Done: Timescale schema, dual-write, continuous aggregates, compression/retention.

              - Open: benchmark p95, cutover read traffic, ERP/file/MES connectors + admin dashboard.

              - Connector schema/DLQ framework đã có; implement concrete còn thiếu.

            B · Event & AI · ~45%

            CEP, prediction & RCA

              - Done: CEP ADR, event schema, rule samples, in-process EventRuleEngine, alert/prediction APIs, z-score baseline.

              - Open: migrate alarm rules legacy, latency report (<1s p95), ML models thật, RCA API.

              - Alert lifecycle + dedup/suppression persistence đã ship.

            C · Core backend · ~65%

            Asset modeling & security

              - Done: asset schema/asset_id, CRUD/search/tree, document metadata, health score formula + job + APIs.

              - Open: seed 50+ assets end-to-end, RBAC scopes, rate limit, RFC 7807 chuẩn hóa.

              - Import template docs đã có; seed production-like còn thiếu.

            D · Frontend & QA · ~50%

            Product surface & evidence

              - Done: UI shell, Asset Browser, dashboard health/alert slice, machine health UI, shared SSO demo flow.

              - Open: Alert Center actions, Asset Browser health roll-up, CSV export, Playwright E2E, perf/security audit.

              - Sync W5 happy-path component coverage partial; browser E2E chưa chốt.
